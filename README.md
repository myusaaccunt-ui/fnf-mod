# STICKMAN: BROKEN REALITY

This repository has been rebuilt to follow a vanilla FNF 0.8.8 mod layout rather than the Psych Engine layout.

Repository layout:
- `mods/Stickman_Broken_Reality/` contains the actual stage/character/song mod package.
- `data/characters/`, `data/stages/`, `data/weekData/`, and `data/charts/` are vanilla-style paths used by the engine.
- `songs/broken-reality/` is the expected runtime asset directory for the final original audio.

Missing binary assets that must still be provided by the user:
- `mods/Stickman_Broken_Reality/songs/broken-reality/Inst.ogg`
- `mods/Stickman_Broken_Reality/songs/broken-reality/Voices.ogg`

No copyrighted SSV3 or other third-party content is included.
