# Installation

1. Download the repository ZIP and extract it.
2. Open the extracted `mods/Stickman_Broken_Reality` directory.
3. Copy that directory directly into the FNF 0.8.8 Android `mods` directory.
4. Confirm `_polymod_meta.json` is directly inside `Stickman_Broken_Reality`.
5. Add the original audio files at:
   - `assets/music/broken-reality/Inst.ogg`
   - `assets/sounds/broken-reality/Voices.ogg`
6. Restart FNF and open the mod menu.

Do not install this as `mods/fnf-mod-main/mods/Stickman_Broken_Reality`; that nesting prevents discovery.
