# Polymod asset-root marker

This directory mirrors the game's asset root for vanilla FNF 0.8.8 mod loading.

The mod must be installed as:

`<game>/mods/Stickman_Broken_Reality/`

with `_polymod_meta.json` directly beside this directory. Do not install the repository wrapper folder itself.

Expected audio locations for the current runtime layout:

- `assets/music/broken-reality/Inst.ogg`
- `assets/sounds/broken-reality/Voices.ogg`

If your Android build uses the legacy song resolver, use the documented fallback paths under `songs/broken-reality/`.
